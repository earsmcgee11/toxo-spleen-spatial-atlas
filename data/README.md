# Data (not stored in this repository)

Large analysis objects are kept outside git. Set local paths in notebooks or via environment variables.

## Expected objects

| Role | Example filename(s) |
|------|---------------------|
| Filtered Visium AnnData | `filtered_spot_adata.h5ad` |
| scRNA atlas | `sc_spleen_072225.h5ad`, `sc_spleen_clean_022526.h5ad` |
| cell2location infected / uninfected | `cell2location_*_yk.h5ad` |
| Combined deconvolution object | `processed_deconvolution_sc_spleen_240713_fixed_full_data.h5ad` |
| Annotated Visium | `1_18_25_visium_annotated.h5ad` |

## Public deposition (from manuscript)

Processed scRNA-seq and Visium data will be deposited in GEO and available through CELLxGENE upon publication. Loupe Browser files for Visium samples will be available at Zenodo upon publication.
